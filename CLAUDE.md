# CLAUDE.md

The instructions for this repo live in **[AGENTS.md](AGENTS.md)** — same content, a name
that is not tied to one tool. Read it before changing anything.

If you are touching how the card talks to met.no, the part that matters most is
*Rules for talking to met.no*. Those are not style preferences: met.no's 20 requests per
second is a limit on the whole card across every installation, not per user, so breaking
one of them gets the card banned for everybody at once.
